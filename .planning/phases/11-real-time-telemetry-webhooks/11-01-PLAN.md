## Technical Context & Invariant Constraints

1. **Discord Zinc Aesthetic (UI-Spec Compliance):**
   - Visual embeds must strictly adhere to the Zinc palette (`#09090b` background, `#18181b` card surfaces, `#22c55e` emerald profits, `#ef4444` red stop-outs, `#3b82f6` blue info).
   - Rich fields with formatted numbers: SOL amounts to 4 decimals, USD amounts to 2 decimals, percentages with sign (`+9.12%`), clickable Solscan and DexScreener links for mints and pools.
   - Built-in rate limiter preventing Discord 429 webhook bans (max 30 alerts/minute with token bucket).

2. **Telegram Operator Bot Security & Interactivity:**
   - Asynchronous Telegram Bot operating via `httpx` or non-blocking HTTP pooling.
   - Chat ID authentication: Every incoming command must match configured `TELEGRAM_ALLOWED_CHAT_IDS` or `TELEGRAM_OPERATOR_CHAT_ID`. Unauthorized queries must be immediately dropped with a security log and alert event.
   - Interactive command set:
     - `/status`: Returns engine state (RUNNING/PAUSED), active positions count, circuit breaker remaining budget ($10.00 ceiling), bankroll allocation ($25 active, $75 cold reserve), Helius slot & latency, fastest Jito region.
     - `/kill`: Engages `EmergencyKillSwitch` atomically with reason "Telegram operator remote panic stop". Halts the engine immediately and dispatches high-priority alert.
     - `/reset`: Resets `EmergencyKillSwitch` with operator name and safety notes.
     - `/circuit_breaker`: Checks daily loss tally, trade count, and reset option.
     - `/positions`: Detailed breakdown of currently open positions, trailing ratchet status, and stop price.
     - `/help`: Operator guide to available commands.
   - Mock/Offline Mode: Operates cleanly without errors when Telegram credentials are not configured or when testing offline.

3. **Streamlit Live WAL Real-Time Streaming:**
   - SQLite WAL (Write-Ahead Logging) reader that queries SQLite state without locking writers or causing database concurrency errors (`timeout=10.0`, `journal_mode=WAL`).
   - Auto-refresh mechanism (`st.rerun` or periodic fragment reload) allowing hands-free terminal monitoring.
   - Interactive Operator Control panel directly in the UI:
     - One-click Panic Stop (`Trip Kill Switch`).
     - One-click Emergency Reset (`Reset Kill Switch`).
     - One-click Circuit Breaker Reset.
     - Live Event Log Stream displaying recent alert events with severity badges.

4. **Integration with `MasterTradingOrchestrator`:**
   - Wire `TelegramOperatorBot` lifecycle into `MasterTradingOrchestrator` startup (`start()`) and shutdown (`stop()`).
   - Wire webhook alerts to all orchestrator events (candidate passed, position opened, ratchet updated, TP1 hit, position closed, risk halt).
