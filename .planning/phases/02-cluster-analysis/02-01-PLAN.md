# Phase 2: Cluster Analyzer & Risk Scoring Engine — Phase Plan

**Phase:** 02-cluster-analysis  
**Milestone:** Milestone 1 — Observational Telemetry & Falsification Architecture (v2.5)  
**Deliverables:** 2-Hop Funding Graph Engine + Fresh Burner Wallet Detector + Sybil Heuristics + Mint/Freeze Safety Checker + Aggregated Risk Scoring  
**Strict Invariants Enforced:**
