## Technical Context & Invariant Constraints

1. **The 12 Checks Entry Gate (100% PASS Gate):**
   - Check 1: Age Window (8.0m to 25.0m post-graduation).
   - Check 2: Canonical Pair (`quote_mint == WSOL`, canonical PumpSwap program).
   - Check 3: Velocity of Unique Wallets ($VUW \ge 1.20$, or $1.05$ in `REGIME_TEST`).
   - Check 4: Aggression Ratio ($Taker Buy / Taker Sell > 2.00$).
   - Check 5: Baseline Demand Floor (60s net taker buy $\ge \$100/\text{min}$, or $\$50/\text{min}$ in test).
   - Check 6: Freeze Authority permanently revoked (`freeze_authority_option == 0`).
   - Check 7: Mint Authority permanently revoked (`mint_authority_option == 0`).
   - Check 8: Top-10 Retail Concentration $\le 25.0\%$ (excluding bonding curve PDA).
   - Check 9: Dynamic Liquidity Floor ($\ge \$3.00$ size with price impact $\le 1.5\%$).
   - Check 10: Pre-Trade Risk Capacity ($\text{Stressed Loss} + \text{Exit Reserve} \le \text{Remaining Daily Budget}$).
   - Check 11: Emergency Exit Reserve ($\ge 0.005$ SOL balance post-trade).
   - Check 12: WS Data Freshness ($\le 1000\text{ ms}$ latency).

2. **Invariant 2 & Path A+ Exit Enforced:**
   - Primary Mode: `Path A+` (100% position trailing exit, strictly 2 swaps total, zero tranche dilution).
   - Optional Mode: `Tranche/Runner` (90% TP1 scale-out + 10% runner) available for accounts with $\ge \$50$ position size.

3. **Deterministic FSM Transitions:**
   - Illegal state jumps (e.g., `IDLE` → `RUNNER_ACTIVE` or `CLOSED` → `ACTIVE_OPEN`) raise strict `IllegalStateTransitionError`.
