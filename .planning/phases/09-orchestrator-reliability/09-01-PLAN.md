## Technical Context & Invariant Constraints

1. **Deterministic Concurrency & Concurrency Overrides:**
   - Single-position active constraint (strict 1 concurrent trade, or 3 concurrent trades when `is_regime_test == True`).
   - Priority-based event queues: `HIGH` (liquidations, stops), `MEDIUM` (12-check gate), `LOW` (telemetry writes).
   - Thread-safe state mutation protected via `asyncio.Lock`.

2. **Zero Data Loss on Restarts (Crash Recovery):**
   - SQLite WAL mode journal (`orchestrator_state.db`) writing state updates before external execution triggers.
   - Startup reconciliation re-hydrating active positions and validating against wallet on-chain state.

3. **Production Safety & Circuit Breakers:**
   - Immediate event loop halt upon WebSocket latency exceeding 1,000ms staleness ceiling.
   - Emergency Kill Switch integration persisting lockout state across process restarts.
   - Graceful shutdown handling SIGINT/SIGTERM with active state persistence.
